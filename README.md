# MSc Computer Science – Full Stack Development Practicals

Hey! This repo has all the **Full Stack Development practical programs** for **MSc Computer Science**. The whole point is to build actual working web apps instead of just boring theory stuff. Each program is in its own branch so you can check them out separately.

---

## Practical Programs

| Program | Name | What's it about |
|:-------:|:-----|:----------------|
| **1** | **Login Authentication System** | Develop and demonstrate a program for login authentication. |
| **2** | **Simple Discussion Board** | Create a simple Discussion board for students to share their knowledge |
| **3** | **College Website Using Themes** | Build a college website using Themes. |
| **4** | **Homepage with Admin Panel** | Create a homepage and customize the data through Admin Panel |
| **5** | **Online Survey Application** | Develop an online survey application where a collection of questions is available and users are asked to answer any random 5 questions |
| **6** | **Leave Management System** | Develop a leave management system for an organization where users can apply different types of leaves such as casual leave and medical leave. They also can view the available number of day |
| **7** | **Classifieds Web Application** | Develop a classifieds web application to buy and sell used products |
| **8** | **Personal Portfolio Website** | Develop a portfolio website for yourself which gives details about yourself for a potential recruiter. |

## Project Structure

Each program lives in its own branch so things don't get messy.

```
msc-fullstack-practicals/
│
├── main (branch)                    → This branch with docs
├── login-authentication (branch)    → Program 1
├── discussion-board (branch)        → Program 2
├── college-website (branch)         → Program 3
├── leave-management (branch)        → Program 4
├── online-survey (branch)           → Program 5
├── classifieds-app (branch)         → Program 6
├── admin-panel (branch)             → Program 7
└── portfolio-website (branch)       → Program 8
```

## How to Use

1. Clone this repo
   ```bash
   git clone <repository-url>
   ```
2. Switch to whatever program you wanna work on
   ```bash
   git checkout login-authentication
   ```
3. Check the README in that branch for setup instructions
4. Install packages and run it
