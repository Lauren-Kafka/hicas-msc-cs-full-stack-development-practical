# MSc Computer Science – Full Stack Development Practicals

This repository contains the **Full Stack Development practical programs** for **MSc Computer Science**, developed as part of the academic curriculum.  
The main idea behind this repository is to apply full stack concepts through hands-on implementation, focusing on real-world style web applications rather than just theoretical examples.

Each practical is implemented as a separate program and is aligned with the respective **Course Outcomes (COs)**.

---

## 📘 Course Outcomes & Practical Programs

### CO1 – Login Authentication System
Develop and demonstrate a program for user login authentication, focusing on secure access and basic authentication flow.

---

### CO1 – Simple Discussion Board
Create a simple discussion board that allows students to share knowledge, ideas, and messages in a structured way.

---

### CO2 – College Website Using Themes
Build a college website using predefined themes, concentrating on layout design, navigation, and content presentation.

---

### CO5 – Homepage with Admin Panel
Create a homepage where data can be customized and managed through an admin panel, introducing the concept of administrative control and dynamic content updates.

---

### CO4 – Online Survey Application
Develop an online survey application where a collection of questions is available and users are required to answer **any random five questions**.

---

### CO3 – Leave Management System
Develop a leave management system for an organization where users can apply for different types of leave such as casual leave and medical leave, and also view their available leave balance.

---

### CO4 – Classifieds Web Application
Develop a classifieds web application that enables users to buy and sell used products, focusing on listings, user interaction, and basic workflows.

---

### CO5 – Personal Portfolio Website
Develop a personal portfolio website that presents personal details, skills, and projects for potential recruiters.

---

## 🛠 Technologies Used
- **Frontend:** HTML, CSS, JavaScript (and frameworks if applicable)
- **Backend:** Node.js / Express (or equivalent backend technologies)
- **Database:** SQL / NoSQL (based on the program requirements)
- **Tools:** Git, npm, modern web development practices

---

## 📂 Project Structure

Each practical program is organized into its own folder for clarity and ease of execution.
